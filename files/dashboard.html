Training Pipeline

1
GAN Pre-training (50 epochs)
WGAN-GP trains Generator & Discriminator on real MRI scans. Generator learns to synthesise realistic tumour images. Gradient penalty enforces Lipschitz constraint.
2
Warmup Phase (epochs 1–10)
Linear LR warmup from 0 → 3e-4. Model learns basic tumour/no-tumour distinction. EMA shadow model initialised.
3
Main Training with GAN Augmentation (epochs 11–100)
30% of each batch replaced by GAN-synthesised images. Mixup + CutMix applied alternately. AdamW with cosine annealing. Label smoothing ε=0.1. Gradient clipping at 1.0.
4
EMA Model Evaluation
Exponential moving average (decay=0.9999) of weights used for validation — produces smoother, more generalised model. Best EMA checkpoint saved.
5
Test-Time Augmentation (TTA)
3 augmentation views averaged at inference: original, horizontal flip, centre-crop. Adds ~0.3% accuracy boost over single-pass inference.

def forward(self, x):
    # ① Extract global features via Vision Transformer
    vit_feat = self.vit_proj(self.vit(x))         # (B, 512)

    # ② Extract local sequential features via Mamba SSM
    mamba_feat = self.mamba_proj(self.mamba(x))   # (B, 512)

    # ③ Cross-attention: ViT queries over Mamba features
    v = vit_feat.unsqueeze(1)
    m = mamba_feat.unsqueeze(1)
    fused, _ = self.cross_attn(v, m, m)
    fused = self.fusion_norm(fused.squeeze(1) + vit_feat)

    # ④ Concatenate & classify
    combined = torch.cat([fused, mamba_feat], dim=-1)
    return self.classifier(combined)   # (B, 2)

Quick Start

bash — Setup & Train 
# Install dependencies
pip install -r requirements.txt

# Download BR35H from Kaggle
kaggle datasets download \
  -d ahmedhamada0/brain-tumor-detection

# Prepare dataset splits
python dataset.py --prepare

# Train (base model, 100 epochs)
python train.py \
  --data_root data/BR35H \
  --epochs 100 \
  --batch_size 32 \
  --model_variant base

# Evaluate on test set
python evaluate.py \
  --checkpoint checkpoints/best_model.pth
python — Single image inference 
from dataset import Predictor
from PIL import Image

# Load trained model
predictor = Predictor(
    'checkpoints/best_model.pth'
)

# Run prediction with TTA
img = Image.open('mri_scan.jpg')
result = predictor.predict(img, use_tta=True)

# Output
print(result)
